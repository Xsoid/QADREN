## Статусы

- **Принято** — согласованное архитектурное правило.
- **Предложено** — вариант реализации, ещё не утверждён.
- **Требует проверки** — допущение о поведении системы, API или ОС.
- **Отложено** — за пределами текущего проектирования.

При изменении принятого решения обновлять соответствующий документ и журнал решений, не подменяя историю молча.
