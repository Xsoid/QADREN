# BackupSet и резервные версии — отложенная концепция (v0.5)

**Не входит в MVP / релиз 1. Не является активным контрактом Core, БД, API или UI.**

Историческая архитектура QADREN v0.5 предполагала BackupSet с двумя или более подтверждёнными защищёнными копиями, версионирование файлов, tombstone/retention и восстановление конкретной исторической версии. Её исходное описание сохранено в истории Git и в прежних D-001/D-002/D-009. Текущая архитектура вместо этого использует Scenario, Job и метаданные последнего согласованного состояния для синхронизации.

При возвращении к backup-функциям потребуется отдельный ADR по модели хранения, политике retention, proof-of-copy, совместимости с Scenario, механизмам восстановления и миграции. Не подмешивать BackupSet или обязательное сохранение старого содержимого в текущий механизм синхронизации. Ни наличие истории метаданных, ни корзина провайдера не гарантируют восстановления прежней версии.
