## Пересмотр 2026-10-09 — спецификация v0.2

Согласовано: QADREN ориентирован на синхронизацию, а BackupSet/версии резервных файлов отложены; актуальны Scenario/Job, служебная история последних подтверждённых состояний без хранения содержимого, усиленная защита опасных операций, собственный iCloud Documents container и независимый Local Filesystem adapter. Релиз 1 — полноценный локальный Controller+Worker, релиз 2 — удалённые Worker. Исторический смысл D-001/D-002/D-009 сохранён, но их старые формулировки **не являются активными требованиями MVP**. См. [спецификацию](../architecture/backup-model.md) и [BackupSet future](../architecture/backup-model.md).

## Пересмотр 2026-10-12 — iCloud отложен

[D-017](D-017-defer-icloud.md) переопределяет iCloud-часть D-003 и D-012: собственный iCloud Documents container, iCloud backup/sync и native spike не входят в Release 1; Local Filesystem независим и активен. Защита от случайного скачивания iCloud/File Provider placeholders через Local FS остаётся.

## Правило изменения

При пересмотре решения сохранить ID, описать новое решение, причину и затронутые документы. Новые детали оформлять в `docs/decisions/` отдельными ADR при необходимости. Нельзя считать предложение утверждённым без явного решения.
