# QADREN

**QADREN** — проект компактной кроссплатформенной системы резервирования и обмена данными между независимыми хранилищами и узлами.

> Статус: проектирование. Архитектурная спецификация v0.4, 2026-10-08. Код приложения ещё не реализован.

## Цель

Один и тот же защищаемый набор данных должен иметь две или более контролируемых копий, насколько это допускают возможности подключённых хранилищ. Отказ одного облака, конфликт правок или удаление файла не должны незаметно уничтожать последнюю подтверждённую резервную версию.

Первые интеграции:
- **Яндекс Диск** — через официальный API.
- **iCloud Drive** — через **собственный видимый пользователю iCloud Documents container**; соответствующий адаптер зависит от macOS.

## Ключевые решения

- Отдельные правила для разных папок и наборов данных: Яндекс → iCloud, iCloud → Яндекс, двусторонний обмен.
- Кроссплатформенное ядро; адаптеры сообщают совместимость с ОС и поддерживаемые операции.
- Одно приложение может исполнять роли управляющего узла (Controller) и исполнителя (Worker).
- Главный MacBook — центр управления, не обязательный посредник передачи файлов.
- **QADREN не скачивает содержимое в локальное хранилище основного MacBook без предварительного согласования.** Системный iCloud и другие программы не ограничиваются.
- Делегированное задание выполняет только назначенный Worker; Controller принимает его отчёт, не дублируя исполнение.
- Удаления и конфликты не должны незаметно уничтожать защищённые версии.
- Протокол связи экземпляров приложения пока **не проектируется**.
